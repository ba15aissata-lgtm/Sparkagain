# Sparkagain

A daily habits and self-discipline tracker. Build consistent routines across
six areas of life: **Discipline**, **Sports**, **Diet**, **Hygiene**,
**Self Care**, and **Outfit of the Day**.

## Features

- **Today** — a daily checklist grouped by category, with a completion ring
  and per-habit streak counters.
- **History** — a monthly calendar heatmap of completion rate; tap a day to
  see what you finished.
- **Stats** — 7-day trend, per-category completion rate, and all-time best
  streaks.
- **OOTD** — a photo journal for outfit of the day, with tags and a
  confidence rating.
- **Manage** — add, archive, or delete habits and assign them to a category.

All data is stored locally in the browser (`localStorage`) — no account or
backend required.

## Development

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
```

Built with React, TypeScript, Vite, Tailwind CSS, and Zustand.
